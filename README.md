# Student Management System

## Description
A Student Management System developed using HTML, CSS, Python Flask, and MySQL.

## Features
- Add Student
- View Students
- Update Student
- Delete Student

## Technologies Used
- HTML
- CSS
- Python
- Flask
- MySQL

## How to Run
1. Install Python.
2. Install the required packages:
   pip install -r requirements.txt
3. Import database.sql into MySQL.
4. Run:
   python app.py
