# 🎓 Student Management System

A Student Management System developed using **Python Flask** and **MySQL**. This project helps manage student records efficiently with a simple and user-friendly interface.

---

## ✨ Features

- ➕ Add Student
- 👀 View Students
- ✏️ Update Student Details
- ❌ Delete Student
- 📱 Responsive User Interface
- 💾 MySQL Database Integration

---

## 🛠️ Technologies Used

- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript

## 🚀 How to Run

1. Clone the repository

```
git clone https://github.com/Neha123112/Student_Management_System.git
```

2. Open the project folder

3. Install dependencies

```
pip install -r requirements.txt
```

4. Import `database.sql` into MySQL

5. Run the project

```
python app.py
```

6. Open your browser and visit:

```
http://127.0.0.1:5000
```
